# VEA-P2-T001D-R1 — Harden real-run and resume readiness

## Objective

Remove deterministic pre-stage failures from the accepted T001D harness while
preserving its scientific formulas, identities, split, conditions, artifact
schemas, atomic publication, and 2,345-unit checkpoint plan.

## Recovery changes

- Treat an omitted reuse root as an exact optional `null`, never as a path.
- Estimate storage from every actually persisted tensor and metadata class,
  including duplicate native Stage 05 tensors and the largest atomic partial.
- Bind all four anchor-registry units to the exact ordered 128 anchor IDs.
- Bind real plans to the approved main Python, TinyLLaVA overlay, cache paths,
  offline environment, and package metadata without pre-gate heavy imports.
- Construct a DINO-specific worker environment that strips main-lane paths while
  preserving offline/cache variables; main stages retain the approved overlay.
- Count each DINO one-forward extractor worker as one actual model load.
- Keep the reviewed repository and run root under persistent Apple parents.
- Generate a parent-safe detached supervisor with a bounded, resource-only
  resume policy and accurate worker/tee/verify/finalize statuses.

## Local definition of done

- A no-reuse fake plan completes interruption, partial verification, resume,
  complete verification, finalization, and status without optional-path errors.
- Completed chunks and generations are not rewritten and the resumed result is
  byte-equal to the uninterrupted counterfactual under the same plan ID.
- Old-pass/new-fail storage boundary and independent persisted-payload
  calculations prove the corrected gate is active and conservative.
- Injected subprocess and 63-chunk DINO regressions prove isolation and runtime
  accounting without importing or executing a real model.
- Only the assigned CPU/fake checks run locally; the corrected persistent Apple
  run remains a separate post-review action.

## Non-goals

No scientific formula, encoder/VLM identity, data selection, chunking, condition,
artifact schema, dependency, model, dataset, checkpoint, Apple/CUDA execution,
package installation, merge, downstream task, or automatic non-resource retry is
introduced by this recovery.
